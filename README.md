# OKLEYKA.PRO · Санкт-Петербург

Сайт детейлинг-центра OKLEYKA.PRO (Автополе Кудрово): оклейка плёнкой, керамика, полировка, химчистка.

Демо: https://rootvandal.github.io/okleyka-pro/

- Статика без сборки: `index.html`, `assets/css/style.css`, `assets/js/app.js`.
- Весь контент (работы, услуги, цены, вопросы) — в `assets/js/data.js`.
- Фото и видео — только из публикаций самого центра (фильм о центре, съёмки машин, ролики). Чужих и стоковых материалов на сайте нет.

Запуск локально: `python -m http.server 8806` и открыть http://localhost:8806
